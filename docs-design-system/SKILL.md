# SecurityPal Document Design System

Read `README.md` in this folder before producing or reviewing any SecurityPal document. It is binding. Look at the pages in `reference/` for the approved look.

Non-negotiables:

1. A4 portrait, 0.8 in margins, white pages. Only the cover is colored (Brand Blue).
2. Geist only. Sizes are 8 · 10 · 11 · 14 · 18 · 34 pt and nothing else. H1 is 18 pt `#015CE6`, H2 is 14 pt `#828282`, body is 11 pt `#121212`. There is no H3.
3. Six colors: `#015CE6`, `#121212`, `#828282`, `#E8F1FF`, `#F0F4F9`, `#FFFFFF`. Blue shades are for charts only.
4. Two-column body (30% H2 label / 70% content), left-aligned, never justified, generous whitespace. Start a new page rather than cram.
5. Tables: 10 pt text, blue or black header with white text, body fill paired to its header (blue → `#E8F1FF`, black → `#F0F4F9`), 3 pt white borders, 0.1 in padding. Use one header pattern per document.
6. Charts use blue shades only, with the name below as an italic caption (***Image:*** … / ***Table:*** …).
7. The same 8 pt footer on every body page: *Confidential* and a date pill on the left, the document title and *Prepared by SecurityPal AI* on the right.
8. Finish by walking the 35-item QA checklist in README §12.
